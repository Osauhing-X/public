# Forms, surveys and CRM

Forms / Surveys collects structured Website responses. Customers CRM keeps private customers, companies and follow-up activities. These are separate installed packages, not one automatically shared tenant table.

## Form setup

Install Website and attach the compatible Forms / Surveys instance. Configure fields, validation, public availability and the response workflow. Place its declared import token through Routes.

Ask only what the purpose needs. Show a privacy explanation and avoid collecting payment-card information or unnecessary sensitive details.

## CRM setup

Create a customer or company, add the relevant relationships and follow-up activity, then reload to verify persistence. Archive/restore is different from permanently deleting data.

A public form does not automatically prove a CRM record was created. Verify the linkage implemented by the installed package; if no automated link exists, use an explicit reviewed workflow.

## Acceptance

Submit one disposable public response, verify it in the correct instance, test invalid fields and duplicate handling, and confirm a logged-out visitor cannot list private responses. Keep contact requests and marketing consent separate.
