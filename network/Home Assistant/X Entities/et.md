# X Entities

X Entities avastab ühilduvad Node.js rakendused Zeroconfi kaudu, võtab vastu nende olekusnapshote ja loob Home Assistantis dünaamilised olemid. Rakendus saadab oleku integratsiooni API-sse ning lüliti- ja nupukäsud liiguvad tagasi rakenduse `/update` otspunkti. Allika heartbeat muutub katkestuse korral unavailable-olekusse ning aegunud allikas eemaldatakse.
