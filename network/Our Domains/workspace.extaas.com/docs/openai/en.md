# AI integration: v2 status

This page preserves old documentation links. The current public Workspace v2 package collection does not ship an OpenAI integration. The v1 AI-composer setup is not available merely by entering an API key.

If you build an AI integration, use the [integration tutorial](/en/docs/create-integration) and explicit consumer action scopes. Do not send secrets or unnecessary customer data to a model. Review generated content before publishing.

Adding a provider package, its server action and a compatible consumer is separate implementation work. Do not advertise a built-in AI capability until that implementation and its actual workflow are verified.
