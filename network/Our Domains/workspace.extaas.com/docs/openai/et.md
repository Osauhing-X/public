# AI-integratsioon: v2 hetkeseis

See leht säilitab vanade doksilinkide toimimise. Praegune avalik Workspace v2 paketikogumik ei sisalda OpenAI integratsiooni. V1 AI-koostajat ei saa kasutusele võtta pelgalt API võtme lisamisega.

Oma AI-integratsiooni loomiseks kasuta [integratsiooni õpetust](/et/docs/create-integration) ja selgeid tarbija toiminguõigusi. Ära saada mudelile võtmeid ega tarbetuid kliendiandmeid. Vaata genereeritud sisu enne avaldamist üle.

Teenusepakett, serveritoiming ja sobiv tarbija vajavad eraldi teostust. Ära luba sisseehitatud AI-võimekust enne selle ja tegeliku töövoo kontrollimist.
